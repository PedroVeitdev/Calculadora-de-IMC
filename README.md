# Calculadora de Índice de Massa Corporal (IMC)

Crie esta aplicação para colocar em prática meus primeiros estudos em python. Trata-se de um projeto simples, mas essencial para construir uma base sólida no desenvolvimento com Python.

# Objetivo

Este projeto foi criado para aplicar e fixar os seguintes conceitos básicos de programação:

- **Entrada e Saída de Dados:** Manipulação de `input()` e `print()`.
- **Conversão de Tipos (Casting):** Tratamento de dados numéricos (`float`).
- **Operadores Aritméticos:** Cálculos matemáticos como divisão e potenciação (`/`, `**`).
- **Estruturas Condicionais:** Lógica de decisão utilizando `if`, `elif` e `else`.
- **Formatação de Strings:** Uso de *f-strings* e formatação de casas decimais (`{imc:.1f}`).


# Exemplo do Uso

Cálculo do Índice de Massa Corporal (IMC)

Digite seu nome: **Maria**

Digite seu peso (kg): **65.5**

Digite sua altura (m): **1.68** 

Calculando seu IMC, aguarde...

**Maria, seu IMC é 23.2. Você está no peso normal.**


**Nota:** *Os valores (Maria, 65.5 e 1.68) foram utilizados apenas como exemplo do que o usuário digita no terminal. O programa calcula o IMC em tempo real para qualquer outro dado inserido.*
